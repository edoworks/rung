# Rung 0.3.0

Release scope: Rung 0.3.0 packages the free MIT-licensed repository
governance-evidence engine for provenance-backed publication. This document
does not establish that any registry or release channel completed publication.

## Included

- Eleven deterministic checks over public repository evidence.
- Six evidence states: absent, claimed, detected, enforced, verified, and
  unobservable.
- A conservative maximum coding-agent authority recommendation.
- JSON and text CLI output.
- Reproducible verification receipts and independent replay observations.
- A dependency-free standalone Python artifact.
- A read-only GitHub Action interface.

## Limits

Rung does not execute code from the repository it audits. Public repository
evidence cannot expose every enforcement setting, so those controls remain
unobservable rather than being guessed. Rung is an assessment aid, not certification,
compliance advice, enforcement proof, or release approval.

The planned $5 paid report is not launched and is not part of this release.
Publication of this release does not establish search indexing, usage,
customers, revenue, or adoption.
