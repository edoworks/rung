# Rung 0.3.2 (unreleased)

Release scope: move public discovery to the verified Edoworks static project
page and make the Rung artifact contract explicit. This release does not
depend on the former laptop-hosted web distribution.

## Included

- Canonical project page at `https://edoworks.com/rung/`.
- Free MIT-licensed Python package and dependency-free standalone CLI.
- Release-path guard rejecting container-runtime dependencies in executable
  release metadata and scripts.
- Reproducible wheel, source distribution, and standalone artifact validation.

## Limits

Rung remains an assessment aid, not certification, compliance advice,
enforcement proof, or release approval. The former `rung.edoworks.com` origin
is not required by the artifacts and remains a separate hosting incident until
the owner retires or redirects it.
